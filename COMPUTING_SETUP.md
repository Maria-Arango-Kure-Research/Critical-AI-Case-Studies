# Computing setup

Before teaching a case, choose a computing environment that can run the notebook and that participants can access. Check the case’s teaching notes for required packages, any memory or GPU requirements, and which environments have been tested.

## Participants run the notebook

Depending on the case and what your participants can access, you can use:

- **A university computer lab** with Python, Jupyter, and the required packages available.
- **A hosted notebook service** such as Google Colab or Paperspace, using a free tier where available.
- **Participants’ own laptops** with Python and Jupyter, or a code editor or IDE that supports Jupyter notebooks, if the case can run on their hardware.

Tell participants in advance which setup you plan to use, whether they need an account, and how to get the notebook and dataset. Give them a way to let you know if they need a different setup.

## The instructor runs the notebook

You can run the notebook on one machine and project it in the room or share your screen online. This format takes more active facilitation because participants follow at the same pace. Pause at key cells to explain what the code does and check how participants are interpreting the output. When there’s a setting to change, ask participants what they want to try and what they expect to happen. Rerun the cell and give them time to compare the results.

## Before the session

Run the notebook from a fresh session in the environment you plan to use. Check that the required packages are available, the dataset loads, and the notebook and any experiments run within the time available. If participants will run it themselves, check that they can access the same setup and files.
