## Performance descriptors

For each criterion, describe what different levels of performance look like in the work. Start with the quality you expect for this activity, then describe how the same aspect of the work varies across the other levels you intend to use. Use the course's grading scale where applicable.

For example, if the criterion is interpreting a model comparison, one response might report that the model scored higher. Another might explain which errors account for the difference. A further distinction is whether the response uses those errors to explain when the difference would matter and identifies what the comparison leaves unresolved.
