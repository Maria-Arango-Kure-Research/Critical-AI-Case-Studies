# Student materials

Read the [Shipment Disruptions scenario](scenario.md) before opening the notebook.

## Setup

1. Open the [student notebook](student-notebook.ipynb) in the environment your instructor has set up for the lab.
2. Download [final_dataset_supply_chain.csv](final_dataset_supply_chain.csv). Upload it to your notebook session or save it in the notebook’s working directory. Keep the filename as written.
3. Run the setup and data-loading cells. The notebook should report 50,000 rows and 19 columns when the data loads.

## During the lab

Run the cells in order and pause at the discussion questions. In each **Try me** cell, change the setting shown and rerun the cell to compare the new result with the original.

The [discussion and reflection questions](questions.md) are also available in a separate file. If your instructor assigns the take-home reflection, follow the three prompts at the end of the notebook.
